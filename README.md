## Clothing Inventory Management System

This is a Python-based console application built to manage clothing products, variants, and stock.

Users can browse categories, select colors and sizes, and add items to a cart. Stock updates automatically when items are added, and the program displays a final cart summary with total price.

This project was developed to practice Python fundamentals and Object-Oriented Programming concepts.

### Features
- Category-wise browsing  
- Product variants (size & color)  
- Shopping cart system  
- Stock tracking  
- Final order summary  

### Learning Outcomes
- Object-Oriented Programming
- List filtering
- Input validation
- Simple backend logic
